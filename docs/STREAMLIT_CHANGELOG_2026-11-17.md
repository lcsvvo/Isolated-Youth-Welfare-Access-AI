# 2026-11-17 Streamlit 변경 기록

이 기록은 원본 참고 자료와 현재 동작의 차이, 구현 판단, 검증 범위를 빠짐없이 추적하기 위한 기술 변경 기록이다. 실제 실행 방법은 [인수인계](STREAMLIT_HANDOFF.md)를 우선한다.

## 시작점·입력

- 사용자가 제공한 `구현.zip`: HTML 1개와 TXT 설계·설명 2개. 참조 원본 보존.
- 초기 로컬 `team-draft/ai/app.py`는 별도 Git 저장소가 아닌 복사본이었음. 작업하지 않고 비교만 수행.
- 기존 workspace의 HTML/Python 초안·별도 분석 폴더를 실제 Git 저장소와 혼합하지 않음.
- 사용자가 지정한 GitHub 저장소의 `feat/streamlit-ui`를 별도 clone. 시작점 `483b5d8`, 앞선 `f2cbbb5`, `815d380`, #87 관련 작업은 기존 팀 작업.
- 작업 전 원격 브랜치 확인·fast-forward pull. 기존 파일 덮어쓰기나 main 직접 커밋 없음.

## 화면 복원

처음에는 원본을 충분히 대조하지 않고 기존 Streamlit 실행만 확인했다. 사용자가 다음 차이를 지적하여 원본 HTML을 추출·직접 비교했다.

- 이용 안내·개인정보와 지금 도움이 필요하다면 링크를 사이드바 하단의 작은 링크로 이동.
- 로고·부제 위치, 새 이야기와 메뉴 사이 간격, 메뉴 아이콘 복원.
- 이번 방문 숫자를 오른쪽의 옅은 사각 배지로 분리.
- 사이드바 하단의 격려 문구·작은 문장·저작권 위치 복원.
- 빈 방문 화면에 네모 카드·심볼·제목·작은 설명·둘러보기 버튼 추가.
- 첫 화면 오른쪽 ‘오늘은, 알아보는 것만으로 충분해요’ 카드와 세 단계 작은 안내 복원.
- 1,100px 이하에서 오른쪽 카드를 무조건 아래로 내리던 규칙 보완. 모바일에서는 별도 처리.
- 인사말 아래로 입력창 이동. 중첩 테두리·아바타·버튼 색상·글꼴·크기·여백 보완.
- 원문 HTML과 같은 색상 체계·큰 제목 명조/본문 고딕 구분 유지.
- 안내·개인정보 화면을 읽기 쉬운 두 패널로 구성. 내용은 실제 메모리 세션·모드·로그 정책에 맞춰 수정.
- 안전 화면을 같은 크기의 긴급/전문 상담 카드로 구성. 당시 브라우저 측정에서 두 카드 높이·폭 같음 확인.
- 연락 링크는 정적이며 자동 발신·신고 기능은 없음. 연락처는 당시 조회 확인 자료 사용. 미래 운영 시 재확인 필요.
- Streamlit 1.67.0의 wrapper/버튼 구조에 맞는 선택자를 사용. CSS 계층·브라우저 폭 변경은 후속 시각 QA 필요.
- 개발자 메뉴는 일반 사이드바에서 빼고 상단 모드 배지/`?dev=1`로 접근.

## 정리표 오류

- 보고 문구: ‘지금은 정리표를 고칠 수 없는 단계예요. 새로운 이야기를 시작해 주세요.’
- 일반 입력→정리표 경로는 로컬 실제 Pipeline+가짜 모델에서 정상 재현. 사용자의 정확한 최초 상태 어긋남 원인은 그 세션에서 확정하지 못함.
- 상태가 어긋났을 때 새 대화를 강요하지 않도록 복구 추가.
- ready/awaiting_answer/explore_only에서 현재 답변·actions·프로필 유지, 확인 라운드의 질문·쿼리 초기화.
- snapshot 복원으로 후속 답변이 사라지는 경로 방지. 위기는 복구를 통해 우회하지 않음.

## 작은 활동 연결

- 기존 Streamlit에는 HTML의 활동 기능이 빠져 있었음.
- 원본 HTML에서 19개 팀 초안과 출처 메타 추출, 임상 검증 자료로 취급하지 않음.
- 막막함·의욕 없음 표현에서 서비스 질문 전에 활동을 볼지 동의 질문.
- 작은 활동 / 서비스 먼저 / 쉬어가기 3가지 선택. 거절 시 대화 재개, 쉼 선택 시 검색하지 않음.
- 동의 후 직접 고른 범위·여유·상호작용 한도 내 최대 3개. 원문처럼 연녹색 카드 구성.
- 서비스 결과·정보 부족 화면에서도 활동으로 진입 가능.
- 초기·자유 답변 모두 위기 확인 우선. 위기 중에는 모든 활동 페이지 차단.
- 실제 모델 자체가 무기력·은둔 단계를 진단하는 기능은 아님. 현재 제안은 문장 규칙.

## 실제 AI 연결·Colab

- 현재 역할: Kanana=위기·추출·추천 이유, bge-m3=의미 검색, BM25/RRF/규칙=검색 결합·조건 검증.
- 로컬 MX450 2GB 확인. 별도 Python 3.13.9 가상환경에 UI·가짜 모델 의존성 설치해 로컬 실행.
- 실제 모델은 T4에서 실행. 최신 코드와 마스터를 ZIP으로 묶어 토큰 없이 업로드, SHA-256 검증.
- Transformers 채팅 호출을 `return_dict=True`, `input_ids`+`attention_mask` 전달 방식으로 정리.
- 실제 모델 연결 실패 시 시연용 가짜로 자동 대체하던 처리 제거, 오류·재연결 표시.
- 임베딩 batch 크기 환경변수 지원, T4 배포에서는 4 사용. 서비스 텍스트를 임의 절단해 품질을 바꾸지 않음.
- 실제 모델 사전 검증에서 일반 카드 5개·추천 이유, 정보 부족, 위기 추천 중단, 메모리 확인.
- 관측값: 초기화 389.46초, 전체 설명 포함 검색 223.1초, peak 8.67GiB/reserved 8.76GiB. 단일 사례.
- 처음에는 서버 실행 성공과 실제 화면 렌더 성공을 혼동. health=200만으로 화면 연결 성공을 선언하면 안 됨.
- Colab proxy와 브라우저 사이 지속 빈 화면 보고. 정확한 현재 proxy origin 허용 + WebSocket 압축 해제 + 새 탭 링크 제공으로 복구. 사용자가 화면 표시·대화 가능을 확인.
- 런타임 초기화로 업로드 폴더 소실 사례. GPU→ZIP→설치→화면 실행 순서 안내. 사전 검증 재실행은 매번 필요하지 않음.
- 동일 파일명 `(1)` 저장으로 upload dict KeyError 발생. 실제 업로드 반환값을 사용해 해결.
- 사용자에게 전달한 일회성 Colab 주소는 세션 한정. 설계/코드의 고정 접속 주소로 보존하지 않음.

## 속도 개선

- 느린 구간 후보: 후보 5개 각각의 Kanana 설명을 순차 생성, 잘못된 JSON·근거 실패에 따른 재시도.
- 사용자 요청에 따라 UI는 `source_first`로 목록·원문 소개 우선 표시.
- 검색/규칙·순위는 유지, 상세에서 요청한 서비스 하나만 설명 생성.
- 생성 설명은 이번 결과 카드에 저장해 재사용. 다른 대화에 자동 재사용하지 않음.
- 연구용 기본 `Pipeline.search(session)`의 기존 전체 설명 생성은 유지.
- `timings_ms` 추가: 쿼리/검색/규칙/설명/전체.
- 개선 후 T4 실측은 아직 없음. 최초 이해·위기 확인과 상세 설명 지연은 별도 남음.

## 말투·지역 오류

- source_first로 기관 원문 소개를 먼저 보이면서 `~함`, `~지원`, `~합니다` 종결이 섞여 나타남.
- 저장 원문은 보존하고 UI 소개 종결형만 정리. 생성 프롬프트에도 해요체 요구.
- 사용자 보고: 서울이라고 했는데 ‘청년 주거비용 지원사업’(전북특별자치도)이 노출.
- 실제 행 `WLF00004762`는 부안군 거주 19~45세 청년 가구 대상.
- 기준의 ‘전국 무주택자’가 `_NON_RESIDENCE`의 넓은 전국 정규식에 걸려 지역 무관으로 잘못 해석됨.
- 전국 자산·주택·중복 검사 범위를 지역 무관 판정에서 제외. 서울 제외·부안 통과·진짜 전국 모집 유지 검증.
- 결과 화면에 현재 지역 조건 표시 추가. 정보 미확인을 서울 확정으로 숨기지 않음.

## OpenAI·자동 갱신 요구 재확인

- 사용자가 ‘AI 연결’을 요청했을 때는 팀의 Kanana/bge-m3 연결로 진행했음.
- 이후 사용자가 OpenAI API는 복지 정보 자동 갱신을 위한 계획으로 기억한다고 설명.
- 기존 공식 API 수집 코드 존재 확인. 하지만 자동 갱신·AI 공고 구조화·앱 데이터 교체는 구현하지 않았음.
- 향후 흐름을 별도 미구현 설계로 분리: 주기 실행→공식 수집→변경 감지→공고 구조화→근거 검증/검수→마스터·색인 교체.
- OpenAI 연결·키·비용·자동화 주기·배포 계정은 아직 정해져 있지 않음.

## 보존·제외 범위

- Git: 런타임 소스·테스트·의존성·실행 노트북·기술 인수인계·원본 디자인 참조 ZIP.
- 별도 공유 묶음: 현재 런타임 ZIP, 과거 복구/패치 파일, 비교용 스크린샷, 원본 구현 ZIP, 전체 작업 기록.
- 미포함: 토큰·`.env`·계정 세션·모델 가중치·캐시·개인 대화·무관한 기존 workspace 작업물.
- 기술 문서를 계획 완료나 실측 완료의 증거로 취급하지 않도록, 구현·관측·미확인 항목을 분리했음.

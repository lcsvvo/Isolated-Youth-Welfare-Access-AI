# Streamlit 화면 설계·유지 규격

실제 구현은 `ai/app.py`의 HTML 조각·CSS·Streamlit 위젯을 함께 사용한다. 원본 HTML은 [참조 ZIP](streamlit-reference/implementation-reference.zip), 시스템 흐름은 [구조도](STREAMLIT_ARCHITECTURE.md), 실행은 [인수인계](STREAMLIT_HANDOFF.md) 참조.

## 시각 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| bg | `#f8f8f3` | 전체 배경 |
| paper | `#fffefa` | 카드·입력 배경 |
| ink | `#263e35` | 본문·제목 |
| muted | `#6e7b72` | 작은 설명 |
| green | `#365f4e` | 주요 버튼 |
| soft | `#eaf0e5` | 보조 선택·상태 |
| line | `#dfe5d9` | 테두리 |
| orange | `#bb8052` | 로고 점·강조 |
| urgent | `#fbf0e7` / `#e6ccba` | 긴급 카드 배경·선 |
| activity | `#f0f4e8` / `#dce4d3` | 작은 활동 카드 |

본문·버튼은 Noto Sans KR/Malgun Gothic, 큰 제목·hero·안내 카드 제목·빈 방문 제목은 Noto Serif KR/Batang. Streamlit의 Material Symbols 아이콘 폰트를 본문 폰트로 덮지 않는다. Google Fonts 외부 요청이 발생한다.

## 배치

- 데스크톱 좌측 레일 246px, 큰 화면 270px, 801~1,100px 구간 210px.
- 주 본문 max-width 1,080px, 데스크톱 topbar 높이 86px. 위젯 padding·Streamlit scrollbar gutter와 중복되지 않게 관리.
- 첫 화면: 왼쪽 대화·입력, 오른쪽 고정 안내 카드 220px(중간 폭 190px). 세 단계 작은 안내는 큰 안내 카드 밖에서 이어짐.
- hero 제목은 데스크톱 43px, 큰 화면 48px, 중간 폭 35px, 모바일 37px. 일반 페이지 제목은 30px/모바일 26px.
- 본문 기본 13px, 작은 설명 11~12px. 글꼴·줄간격·색을 제목과 본문에서 구분.
- 주요 버튼·카드는 둥근 모서리. 일반 버튼 약 44px 이상, 새 이야기 약 50px. 카드 반경 18px.
- 800px 이하에서 홈 오른쪽 안내는 숨김, 도움 카드·활동 카드는 한 열. 모바일 전수 QA 완료를 뜻하지 않음.
- 세로가 짧은 화면에서는 레일 문구·여백을 줄여 하단 링크 접근성을 유지.

## 구성요소·상호작용

| 화면/요소 | 반드시 유지할 내용 |
|---|---|
| 로고 | 위쪽의 반 걸음·심볼·색점·부제 |
| 새 이야기 | 로고 아래 여백, 주요 버튼, 메뉴와 추가 간격 |
| 주요 메뉴 | ◌ 대화 / ▦ 둘러보기 / ◷ 이번 방문 |
| 방문 숫자 | 메뉴 오른쪽에 독립한 옅은 사각 배지 |
| 레일 아래 | 격려 문구·작은 문장 → 구분선 → 작은 이용 안내·도움 링크·저작권 |
| 홈 안내 | 오늘은 알아보는 것만으로 충분해요 + 즉시 신청·모든 질문 응답 불필요 안내 |
| 첫 입력 | 인사말 바로 아래 입력, 예문 버튼·서비스 직접 탐색 |
| 채팅 | 봇 왼쪽·사용자 오른쪽, 이름·말풍선·간격 구분 |
| 정리표 | 알려진 값/선택 보완 구분, 필요 도움·자세한 조건 수정 |
| 결과 | 현재 지역 조건, 원문 소개 먼저, AI 설명은 상세에서 요청 |
| 상세 | 소개/생성 설명과 지원 대상·선정 기준·혜택·신청 원문 분리 |
| 방문 빈 상태 | 테두리 카드·심볼·빈 상태 제목·작은 설명·둘러보기 버튼 |
| 안내·개인정보 | 2개의 가독성 있는 패널. 실제 동작과 맞는 보관·모드 설명 |
| 도움 | 같은 크기의 2개 카드, 명확한 전화/공식 안내 링크, 자동 신고 아님 |
| 활동 동의 | 보기/서비스 먼저/쉬어가기. 동의 전 활동 카드 생성 없음 |
| 활동 카드 | 직접 고른 범위·상호작용 표기, 최대 3개, 연녹색 카드 |
| 개발자 | 일반 레일에서 제외, 상단 배지와 ?dev=1로 접근 |

## 문구와 출처

카드 소개는 해요체로 읽기 쉽게 표시하되 숫자·대상·조건을 새로 만들지 않는다. 생소한 원문은 인용 안내로 보존한다. 상세의 기관 원문은 문체를 이유로 덮어쓰지 않는다. 원문 안내와 AI 생성 설명은 별도 레이블이다.

작은 활동은 팀 초안이며 임상 판정·치료·회복 처방으로 부르지 않는다. 원하지 않으면 선택하지 않거나 쉬어갈 수 있다. 빈 결과와 오류, 입력 부족과 위기는 서로 다른 화면·의미다.

## CSS 수정 시 확인

Streamlit 1.67.0에서 `stLayoutWrapper`, `stVerticalBlock`, 위젯 key class의 감싸는 구조를 확인했다. 앱은 과거 스타일과 후속 override를 함께 갖고 있으므로 셀렉터를 수정할 때 원본과의 시각 비교 및 CSS 우선순위 점검이 필요하다. 상단 상태·입력·모바일 메뉴까지 숨기는 전역 규칙이 생기지 않도록 한다.

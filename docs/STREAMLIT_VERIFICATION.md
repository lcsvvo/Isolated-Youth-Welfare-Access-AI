### 브라우저 화면 및 연결 복구

- 기존 Colab 런타임이 끊긴 뒤 이전 프록시 주소에서 `ERR_CONNECTION_TIMED_OUT`이 발생했다.
- 새 T4에 연결해 같은 `fe1d7aa` ZIP을 다시 올리고, 의존성 설치와 앱 실행 셀을 실행했다. 새 프록시 주소가 발급됐고, 초기 모델 적재 뒤 노트북 안에서 반 걸음 홈과 **실제 Pipeline 연결** 배지를 확인했다. 사용자가 별도 브라우저 탭에서도 같은 홈과 배지를 확인했다.
- 입력창 아래 개인정보·외부 AI 안내 문구 두 줄이 사용자 캡처에서 겹쳤다. 화면 가독성 점검 항목으로 남긴다.
- 다른 팀원 계정에서의 재현, 브라우저 추천 완료 흐름, 상세 AI 설명 생성, Gemini 실제 응답은 확인이 남아 있다.

재현 시에는 위 커밋에서 `python ai/scripts/prepare_runtime.py`와 `python ai/scripts/build_runtime_bundle.py --output bangeol-real-ai.zip`을 실행한 뒤, T4에서 ZIP 업로드, 의존성 설치, 실제 모델 점검, 앱 실행 셀을 순서대로 실행한다.

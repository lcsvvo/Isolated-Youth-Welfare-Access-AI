# Q3 최종 평가 결과 (2026-11-17)

## 후속 평가 (2026-11-18)

- 기존 규칙을 통과한 서비스 중 상위 12개에서 사용자 요청과 실제 지원내용의 혜택 유형을 대조해 재정렬함.
- 개발 질의 30개에서 P@5 **+0.027**. 동일한 Q3 독립 카드 32장에 방법을 고정해 적용한 결과 **0.231 → 0.250**(37/160 → 40/160). 새 Top-5 두 쌍의 사람 판정 포함.
- 규칙 재실행 결과와 저장 Top-5가 다른 1장은 두 방식 모두 저장 순위 사용. 관련성과 서비스 이용 자격은 별도 판정.
- [평가 재현 방법](q3_top5_audit.md)

## 결정

- **선정 검색 구조**: BM25 + BGE-M3(core)를 **RRF(1:1)** 로 결합하고 규칙 필터 적용
- **Q1 +1 가점**: 현행 유지. 이번 32장 평가에서 P@5 개선 근거는 없음

## 평가 범위와 판정 방식

- 독립 평가 카드 80장 중 사전 선정된 **검색 대상 32장**(검수자별 8장, 시드 `q3-subset-v1`)
- BM25·RRF·최종 추천 Top-5 합집합: **323개 서비스–질의 행**
- 관련성: **2점** = 사용자 요청에 직접 도움이 되는 실제 서비스 혜택 / **0점** = 그렇지 않음
- 지역·연령·소득·접근성 등 자격 조건은 관련성과 구분
- 작성자는 자기 카드를 판정하지 않음(교차 배정)
- 2점 55행, 관련 서비스 없는 카드 7장, 판정 범위 안 P@5 상한 0.306

## 결과

| 검색 방식 | Precision@5 | nDCG@5 | Success@5 |
| --- | ---: | ---: | ---: |
| BM25 | 0.088 | 0.192 | 34% |
| RRF | 0.213 | 0.480 | 63% |
| 규칙 적용(Q1=0) | 0.231 | 0.510 | 66% |
| **최종 추천(규칙+Q1)** | **0.231** | **0.527** | **66%** |

| 비교 | P@5 차이 (95% CI) | nDCG@5 차이 (95% CI) | 개선 / 악화 |
| --- | ---: | ---: | ---: |
| RRF − BM25 | +0.125 (+0.056~+0.200) | +0.288 (+0.092~+0.463) | 17 / 4 |
| 규칙 적용 − RRF | +0.019 (−0.013~+0.050) | +0.030 (−0.091~+0.128) | 5 / 2 |
| Q1 가점(+1 − 0) | 0.000 | +0.016 (0.000~+0.038) | 0 / 0 |
| 최종 추천 − BM25 | +0.144 (+0.075~+0.219) | +0.334 (+0.144~+0.510) | 17 / 3 |

- **RRF − BM25**: 개선 방향 명확함. 검수자를 한 명씩 빼도 P@5 +0.08~+0.16 유지
- **규칙 적용 − RRF**: 25장은 P@5 동일. 신뢰구간이 0을 포함해 확정적 개선으로 보기 어려움
- **Q1 가점**: P@5 변화 없음. nDCG@5 5장 개선·1장 악화로 실질적 정확도 향상은 입증 안 됨
- nDCG@5는 관련 서비스가 하나 이상 있는 25장으로 계산
- 최종 추천 P@5는 판정 범위 안 상한(0.306)의 약 75%

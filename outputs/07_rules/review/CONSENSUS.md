# 240행 규칙 검수 합의 반영

- R1~R4는 main의 제출 원본을 그대로 보존. 365행 원본 검수 시트에는 240행을 통합하고 미선정 125행은 유지.
- consensus_log.csv는 원검수값·적용값·사유를 기록. 입력 오류 R1-49 수정, 날짜 형식 통일, R2-35·R4-38·R2-22·R3-40 보수적 재판정. 공식 원문 재검증이 필요한 사례는 확인 필요.
- 연령 제외/보류는 기존 추출값으로 복귀하지 않음. 가구원 조건 별도 기록. 인천 청년도약기지의 기본 범위와 예외는 검수자 근거 기반 조건부 반영.
- 원문 지역 우선. 통합 표기는 자격 확정에 사용하지 않음. 가구원 정보 추가 수집 없음.
- 신청과 이용, 비용 수령과 필수 활동 구분. 검수 근거 부족은 불명. 사용자 방문 불가와 대체 불가 명시가 겹칠 때만 제외.
- 기존 질문·검색·서비스마스터 변경 없음. 테스트는 tests/test_rules_consensus.py, tests/test_rules_overlay.py. 실제 서비스 마스터 비교는 python -m ai.eval.rules_overlay_compare (최신 main 통합 후 실행).
- 이 브랜치는 PR #50 위의 후속 작업. main과 병합하기 전에 최신 main의 나머지 변경을 통합하고 전체 회귀 테스트 및 원문 확인 필요.

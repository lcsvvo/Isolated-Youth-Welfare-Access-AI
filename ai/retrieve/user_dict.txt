# Kiwi 사용자 사전 (한 줄에 "단어 품사 [부분]", #은 주석)
# 여러 명사로 이뤄진 합성어는 통째 토큰과 부분 토큰을 함께 남긴다: 고립은둔 → 고립은둔, 고립, 은둔
# 부분은 보통 자동으로 구한다. 자동 부분이 엉뚱할 때만 셋째 칸에 직접 쓴다: 부분1+부분2, 부분 없음은 -
# 고립은둔: 부분을 직접 지정. 자동 부분은 Kiwi 모델 버전에 따라 달라짐(0.24.0에서는 고+립+은둔으로 나뉘어 부분이 사라짐)
# '은둔'은 따로 등록하지 않음. 등록하면 앞 단어 '고립'이 고+립으로 쪼개짐(0.23.0 문서 2건, 0.24.0 "고립 은둔" 질의)
